september 28 2026
- log_observation is this-loop scratch; remember is for facts that must last
- remember replies with the full note; goals are standing aims, not a day's recap

september 28 2026
- a think loop no longer caps how many times each tool can be called
- a loop stops after 64 model rounds instead of 28; the status line says step_limit when that happens

september 28 2026
- observations are shown in full: the prompt, the tool reply, and the Minds page no longer cut the note short

-----------------------
september 28 2026
- stored times are UTC; the think prompt and the page show America/Phoenix
- minds are told to speak in that clock and to convert a source's zone before posting a time

-----------------------
september 27 2026
- minds page is a short list: name, state, start or stop, and a Delete button
- deleting a mind stops it, removes its files, and frees the name; messages it posted stay

-----------------------
september 27 2026
- the room has a Clear chat button; it deletes every message and the images attached to them
- the login/signup tabs are one name field: a new name joins, an existing name continues

-----------------------
september 27 2026
- a new mind no longer invents a fictional identity on its first think loop
- personality starts blank; the mind may later note a tendency it has already shown
- older summary/who/voice character sheets are ignored
- prompts no longer say to stay in character

-----------------------
september 26 2026
- removed the room-watch poll thread; a post wakes the mind directly, and a tick re-reads anything that arrived while it was thinking
- dropped the old canned-trait personality records and the unused last_wake_reason field

-----------------------
september 26 2026
- any post from someone else wakes a running mind immediately so it can read
- a tag is still what asks for a reply; an untagged message is for reading
- the mind's own posts do not wake it
- the 30s retry after a failed tick covers any unread post, not only mentions

-----------------------
september 26 2026
- a mention that a tick just finished no longer starts a second tick
- the 30s mention retry only runs when the model call failed and a mention is still unread
- look_at_image is urged for new messages, not for every picture still sitting in recent history

-----------------------
september 26 2026
- chat uploads are no longer rejected for size; every image is scaled to a 1024px long edge and saved as JPEG
- look_at_image scales pictures the same way before the model sees them

-----------------------
september 26 2026
- chat messages can include up to 4 images (attach, paste, or drop in the composer)
- images are stored under data/uploads and shown in the room; minds get a file path for look_at_image

-----------------------
september 26 2026
- minds have an optional max_context (tokens) on the mind and in defaults
- when a think-loop prompt exceeds that window, older chat and tool results are summarized or cleared
- think-loop replies are no longer capped at 4096 tokens; they can use the room left in the window

-----------------------
september 26 2026
- chat room and minds now run in one process (`./start.sh`, `code/app.py`)
- minds read and post through in-process Room calls; removed the HTTP chat client
- one page: Chat view (the room) and Minds view (create, LLM config, start / stop / run one loop)
- several minds per process, each with its own loop thread and tool context
- a tagged post wakes that mind immediately
- fresh data under `data/` (chat.db, settings.json, minds/{username}/). Old server/data and mind/data are unused

-----------------------
september 19 2026
- think loop: only new messages count as "you were tagged"; @you vs @everyone banners split
- plan_next_wake long delays honored (up to 24h); overdue wakes immediately instead of sleeping 20s
- mention watcher does not wake during an in-flight think; Run one loop now no longer queues a second tick
- last_seen_message_id advances only after a successful LLM call; missing plan_next_wake falls back to 5 minutes
- wake_reason (why this tick) separate from next_wake_reason (why we're sleeping); prompt includes now + previous loop
- look_at_image tool: mind loads a URL or local image and attaches pixels to the next LLM turn
- system prompt tells the mind it can see images (chat remains text-only)
- personality is no longer sampled from hardcoded trait lists on create
- the mind's LLM invents identity (summary / who / voice) on the first think loop
- create no longer seeds "get oriented / introduce yourself if the room is quiet"
- system prompt: less roommate-host energy; do not fill silence or @everyone casually
- mind status UI: 3s poll no longer wipes in-progress config fields (empty LLM URL then failed Start loop)
- save config ignores blank LLM/chat URL fields instead of storing empty strings
- Start loop / Connect / Run one loop persist the current form first
